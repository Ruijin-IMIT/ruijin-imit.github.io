Scoring formula

CompositeScore = 0.6 × QSM_Score + 0.4 × NM_Score
QSM_Score = 1.0×CN + 1.0×Put + 1.0×GP + 1.2×STN + 1.5×SN + 1.1×RN + 1.0×DN
NM_Score = 2.0×SN
RegionScore = 0.7×Dice + 0.3×(1 − Hausdorff / 10)

The classification ranking used test accuracy as the primary metric. See the submission and scoring archive for the full evaluation protocol.
